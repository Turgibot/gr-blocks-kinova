# gr-blocks-kinova

Goal recognition and responsive help in the Block-words domain (Freedman & Zilberstein, AAAI-17) on a Kinova Gen3
with a Robotiq 2F-140 gripper: simulated in Gazebo first, then on the real arm. The arm is the helping robot
(R_ing); a human is R_ed.

Status: planning. See `docs/PLAN.md`, and `docs/HANDOFF.md` for the facts a new session needs.

Related repos: `GR-Blocks` (symbolic recognition and planning, the source of the cached plans in `data/`),
`kinova-basics` (Gen3 ROS 2 Jazzy setup).
